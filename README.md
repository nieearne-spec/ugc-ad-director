# UGC 带货方案包编译器

把一个产品图和一套产品信息，编译成**可直接执行的带货短视频方案**——最终交付一段能直接粘贴进即梦 / Seedance 的视频提示词。

面向跨境电商与国内电商的短视频带货策划。**不生成视频**，只负责策划、脚本、分镜与提示词。

## 它解决什么问题

有产品、没素材，是带货最常见的卡点：

- 没有真人达人可以出镜
- 不会写目标市场语言的带货脚本
- 抓不住开头三秒的钩子
- 不懂海外用户的镜头节奏与内容习惯
- 不同国家的语言变体、支付习惯、转化路径各不相同，一套话术走不通

这个 skill 把上述环节拆成可复用的流程：上传产品图，回答六个问题，拿到一整套方案包。

## 核心特性

**交付物是一整段提示词，不是黑盒**

最终产出一段连续可复制的视频生成提示词，你能逐字读、逐句改、存下来复用。不存在「提示词模板托管在别人服务器上」的情况。

**三层可插拔架构**

```text
市场层（一个市场一张档案卡）
  ×
品类层（一个品类一条路由）
  ×
通用底座（流程、交付、红线）
```

加一个新市场或新品类，只需新增一张卡片，**不需要改动骨架**。

**提示词双语分层**

画面与镜头描述用英文（模型解析更稳），口播台词用目标市场语言（口型与音频需要）。做英语市场时这两层碰巧同语言，看不出区别；一旦切到西语、葡语市场，如果不分层就会翻车。

**合规约束内置**

禁止编造虚拟达人的第一人称使用体验、禁止使用真人肖像、提供 AI 生成内容标注提醒。这些是硬规则，优先级高于任何「爆款话术」。

## 工作流

```text
上传产品图
   │
   ├─ 识别品类 ──→ 匹配品类路由
   │
   ├─ 确认市场 ──→ 匹配市场档案卡
   │
   ▼
输出「制作前必须确认的 6 件事」
   ① 投放国家/地区   ② 发布平台      ③ 成片口播语言（须到变体级）
   ④ 声音/画面形式   ⑤ 是否已有固定达人  ⑥ 视频时长
   │
   ▼
生成九项方案包
   ① 制作参数确认表      ② 产品与受众判断    ③ 虚拟达人设定
   ④ 达人图提示词        ⑤ 产品图提示词      ⑥ 开头钩子（四类）
   ⑦ 口播脚本（15/30 秒 + 素人版）          ⑧ 镜头清单
   ⑨ Seedance 视频提示词  ← 最终交付物
```

拿到方案包后，用户在自己选定的工具里完成：生达人图 → 处理产品图 → 粘贴提示词 → 生成成片。

## 安装

本仓库本身就是 skill，克隆到支持 `SKILL.md` 的 agent 工具目录即可。

**Claude Code**

```bash
git clone https://github.com/nieearne-spec/ugc-ad-director.git ~/.claude/skills/ugc-ad-director
```

**Codex**

```bash
git clone https://github.com/nieearne-spec/ugc-ad-director.git ~/.codex/skills/ugc-ad-director
```

**通用方式**：把整个目录放进你所使用 agent 的 skills 目录，保持 `SKILL.md` 在根层。

## 使用

调用后上传产品图并说明目标市场。例如：

```text
用 ugc-ad-director 给这个产品做一套墨西哥市场的 15 秒带货方案
```

或直接给出产品信息，让它先识别：

```text
我要给这款唇膏做带货视频，目标市场墨西哥，帮我出方案包
```

skill 会先输出六项确认清单，等你回答后再生成方案包。

## 扩展

**加一个市场**：复制 `references/markets/_template.md` 为 `<市场代码>.md`（ISO 3166-1 小写），逐节填满。市场卡包含语言变体、达人审美、场景、CTA 与转化路径、支付与履约、促销日历、平台权重、监管红线、内容调性、默认组合十节。

**加一个品类**：复制 `references/categories/_template.md` 为 `<品类>.md`，填满八节。品类卡只负责达人形象方向、钩子角度、镜头套路三件事，其余以市场卡为准。

两种情况都不需要修改 `SKILL.md`。

## 设计原则

**不默认，先确认。** 信息不完整时先问，不擅自替用户决定市场与语言。用户明确说「你来定」时才代填，且代填后单独列出待复核。

**语言变体必须写到位。** 西班牙语只写 `Spanish` 会得到欧洲西语的用词和口音。市场卡强制要求标注到变体级（`es-MX`、`pt-BR`、`en-US`）。

**观察与推测分开。** 产品外观描述只能来自产品图观察或用户提供的事实，不得凭品类常识补全——不要给一支哑光唇膏写「水光感」。

**每个卖点都要有镜头。** 写不出对应画面的卖点直接删掉，不留。

**合规高于效果。** 某句话效果再好，踩线就删，不改写成「不那么明显」。

## 合规声明

使用本 skill 生成的方案时，请自行确保：

- 不使用真人（含明星、公众人物、素人）的肖像、声音或可识别特征，除非持有明确授权
- 不编造虚拟达人的第一人称使用经历
- 化妆品、保健品类不宣称治疗、修复病理状态或替代药物
- 按发布平台要求标注 AI 生成内容

不同市场的监管要求不同（如墨西哥 PROFECO 与 COFEPRIS、美国 FTC、巴西 ANVISA 与 CDC），落地前请核对当地规定。详见 [`references/compliance.md`](references/compliance.md)。
