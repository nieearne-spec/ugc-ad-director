# 九项输出契约

方案包固定九项，顺序不可调换。本文件定义每一项的字段与格式。

**通用要求：策划内容用中文，口播台词用目标市场语言，提示词里的画面描述用英文。**
**任何一项都不得留空、不得写「待补充」「视情况而定」。信息不足时回第 2 步追问。**

---

两列表格，把第 2 步收集到的六项答案 + 画面比例复述一遍，供用户复核。

| 项目 | 确认内容 |
|---|---|
| 投放国家/地区 | |
| 发布平台 | |
| 口播语言 | 必须写明变体，如 `墨西哥西语 es-MX` |
| 视频形式 | |
| 达人来源 | 固定达人 / 新建虚拟达人 / 只拍产品 |
| 视频时长 | |
| 画面比例 | 短视频带货默认 9:16 |

表格下方加一行说明：本次方案依据的市场档案卡与品类路由分别是什么。

## 第 2 项　产品与受众判断

五个子块，逐块写完：

**2.1 产品定位**
一句话说清「这是什么、给谁用、解决什么」。不超过 30 字。

**2.2 品类归属与路由**
写明归入哪个品类、依据是什么。若不在现有四类中，注明借用了哪一类。

**2.3 目标受众画像**
- 人口特征：年龄段、性别取向、家庭结构、城市层级
- 使用场景：什么时候、在哪、为什么用
- 核心痛点：他们现在因为这个产品缺失而忍受什么
- 内容消费习惯：在当地平台上爱看什么样的内容

**2.4 需求强度判断**
给结论（强 / 中 / 弱），并给理由。理由要具体到「这个痛点在当地内容生态里是否被反复讨论过」。

**2.5 卖点拆解表**

| 卖点 | Feature（是什么） | Benefit（对用户意味着什么） | 可视化证明（镜头怎么拍出来） |
|---|---|---|---|
| 1 | | | |
| 2 | | | |
| 3 | | | |

规则：每个卖点**必须**有对应的可视化证明。写不出镜头的卖点，删掉，不要留。

## 形态分支：无人出镜时第 3、4 项替换

第 2 步确认的形式为**旁白 / 手部演示 / 只拍产品**时，九项结构作如下替换，其余各项不变：

| 原项 | 替换为 | 内容 |
|---|---|---|
| 第 3 项 虚拟达人设定 | **出镜策略** | 手部设定（同一只手贯穿、肤色、无首饰）、机位视角（如桌面平视偏俯视）、旁白声线（语言变体 + 语速情绪）、与产品的关系（只演示只观察） |
| 第 4 项 达人图提示词 | **参考图策略** | 直接用用户实拍素材作锚点（含实拍视频抽帧），标注素材缺口与补图方案。不需要生达人图 |

替换后第 1 项参数表的「达人来源」写「不需要（无脸出镜）」。无人出镜的额外收益要向用户说明：素材与市场无关，跨市场复用时只需换配音。

## 第 3 项　虚拟达人设定

用表格 + 一段说明。

| 项目 | 设定 |
|---|---|
| 年龄段 | 必须明确为成年人，不得出现年龄模糊的表述 |
| 性别呈现 | |
| 族裔与长相特征 | 必须与市场档案卡一致 |
| 体型与气质 | |
| 生活方式背景 | 职业、居住状态、日常 |
| 常出现的场景 | 2–3 个具体场景 |
| 说话方式 | 语速、用词层次、情绪基调 |
| 与产品的关系 | 首次接触 / 日常使用者 / 送礼者（**不得设定为已使用并验证效果的人**） |

说明段落必须回答一个问题：**为什么是这个人？** 即这个形象为什么能对上目标受众——受众看到她时会觉得「这像我」或「这像我身边的人」。

设定要与品类路由卡片给出的方向一致。不一致时以市场档案卡为准。

---

## 第 4 项　达人图提示词

两条，均为英文，各带 Positive 与 Negative。

**4.1 达人自拍 / 半身照**
用途：作为视频生成的人物参考。

**4.2 达人持产品封面图**
用途：作为视频封面与首帧参考。

写法要求：

- 体型、肤色、发色、妆容等身份特征**放在开头**，权重最高
- 场景、光线、镜头语言紧随其后
- 必须包含「手机前置视角」「自然光」「真实皮肤质感」「拒绝精修感」这类 UGC 质感锚点
- Negative 必须包含：塑料质感皮肤、过度修图、影棚光、模特摆拍感、多余手指、畸形手部、水印、文字
- 不得出现任何真实人物姓名、品牌名（除非用户拥有该品牌）
- 不得包含未成年人的年龄暗示词

---

## 第 5 项　产品图提示词

按需给以下几条，均为英文。

**5.1 产品干净图**
**5.2 产品使用场景图**
**5.3 场景参考图（可选，用作 `@image3`）**——**空场景**：无产品、无手、无人物、无文字，只含成片会用到的环境与道具（如桌面 + 键盘、瓷砖墙 + 镜子）；机位与成片设定一致；光线基调与提示词第 1 层吻合。作用与取舍见 [`reference-images.md`](reference-images.md)。

先判断再执行：**若用户提供的产品图已是干净白底三视图，明确告知 5.1 可以跳过**，不要为了凑齐流程而让用户重复劳动。素材缺某个使用状态（如组装态）时，优先用 5.1 补生成，再进视频生成。

Negative 必须包含：变形、logo 错位、拉链/接口结构错误、融化感、材质失真、水印、凭空添加的细节。

产品外观描述必须**严格来自观察到的产品图或用户提供的事实**，不得凭品类常识补全。

---

## 第 6 项　开头钩子

按四类各给 2–3 条。每条包含：**目标语言原文 + 中文说明 + 适用场景**。

| 类型 | 心理机制 | 适用场景 |
|---|---|---|
| 好奇/测验型 | 用不确定感制造停留 | 产品效果直观但不易描述 |
| 反差型 | 前后对比或预期违背 | 清洁、收纳、改造类 |
| 痛点型 | 直接点名日常困扰 | 有明确使用痛点的品类 |
| 真实体验型 | 平视视角的分享感 | 需要建立信任的高客单品类 |

**「真实体验型」的边界**：可以表达对产品的看法与期待，**不得**编造已经发生的个人使用经历。正确：「我一直在找这样的东西」；禁止：「我用了两周，效果真的不一样」。

钩子用词必须符合市场档案卡给出的语体习惯，不要直译中文爆款句式。

---

## 第 7 项　口播脚本

**同时给三个版本**，不要只给一个：

**7.1 主版（按用户选定时长，通常 15 秒）**
**7.2 扩展版（30 秒，用于需要讲清复杂卖点的场合）**
**7.3 素人口语版（更短的句子、更多停顿、更少的修饰词）**

每个版本用同一张五列表格：

| 时间段 | 口播台词（目标语言） | 画面动作 | 屏幕字幕 | 音效/语气备注 |
|---|---|---|---|---|

时间分配规则：

- 12 秒：0–2 秒钩子 / 2–8 秒核心演示（一镜内可含两个动作）/ 8–12 秒证据 + 收口。镜头数 3 个
- 15 秒：0–2 秒钩子 / 2–7 秒产品出场与卖点 / 7–12 秒证明（在使用状态中呈现）/ 12–15 秒收口
- 30 秒：0–3 秒钩子 / 3–12 秒卖点展开 / 12–22 秒多场景证明 / 22–30 秒收口
- 台词量按目标语言的正常语速折算，且**先区分两种配音形态**（词量不同，见 [`script.md`](script.md)）：
  - **对口型**（真人口播 / 虚拟达人开口）：台词与口型绑定，词量取下限区间；
  - **纯旁白**（无人出镜，后期配音）：无口型约束，可比对口型略满，但同样不要顶满。
  西语语速偏快，15 秒可容纳约 40–48 个单词，30 秒约 85–95 个单词。**写完后按词数核对一遍**，超了就砍。

屏幕字幕与台词不必逐字一致，字幕承担「关键词强化」的职能。

---

## 第 8 项　镜头清单

一镜一行的表格：

| 镜号 | 时间 | 景别 | 运镜 | 画面内容 | 产品状态 | 对应台词 | 风险 | 备注 |
|---|---|---|---|---|---|---|---|---|

填写要求：

- **景别**从中景 / 近景 / 特写 / 大特写中选，不要写「中近景」这类模糊词
- **产品状态**必须写明该镜头里产品的状态（如「未开封」「已打开」「已使用」），用于后续做一致性校验
- **对应台词**引用第 7 项的时间段，不要重抄台词全文
- **风险**标「高」或「常规」。高风险镜头（整面细节展示、镜头内换道具、多步手部动作、翻面、场景切换）在交付时必须给出**单镜测试建议**——生成策略见 [`iteration.md`](iteration.md)
- 镜头数量：12 秒 3 个，15 秒 3–4 个，30 秒 5–6 个。超过这个数量会导致单个镜头过短、画面跳动
- 最后一镜必须包含能让用户看清产品全貌的画面

---

## 第 9 项　Seedance 视频提示词

**这是最终交付物。**必须自成一段、连续可选中、复制后即可粘贴，中间不夹杂中文注释。

四层结构，顺序固定：

1. **风格定调**（英文）—— 整体质感、视角、光线、真实度锚点
2. **时间轴分镜**（英文描述动作与画面 + 目标语言台词）—— 按 `00:00-00:02` 逐段写
3. **引用锚点**（英文）—— 按实际上传素材逐条写 `@image1`、`@image2`……指向什么；**没传的图不得出现对应编号**，锚点数量上限 3 张
4. **约束条件**（英文）—— 产品一致性、手部完整、口型同步、禁止漂移；**不得引用未上传的锚**（场景无锚点时退回纯文字描述）

语言分层是硬规则：

- 画面、镜头、光线、材质描述 → **英文**
- 台词 → **目标市场语言**，且与第 7 项主版逐字一致

写完在末尾另起一段（**不属于提示词本体**），用中文列出使用说明：

```text
使用说明：
1. 本提示词中的 @imageN 为占位引用，数量与编号与实际上传素材一一对应——没传的图不出现在本提示词里。
   请按给定的推荐顺序上传；顺序不同务必手动改掉编号，否则模型不知道在指谁。
2. 台词部分为墨西哥西语：对口型形态请选择支持该语言口型同步的模型；纯旁白形态在成片生成后另行配音。
3. 若生成结果中产品出现变形，把本提示词第 4 层的约束条件原样保留，不要删减。
```

具体编译规则见 [`seedance-prompt.md`](seedance-prompt.md)。
