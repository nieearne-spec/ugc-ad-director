# 品类路由：美妆个护

> 本卡只决定达人形象方向、钩子角度、镜头套路。语言、转化、支付、监管以 [`../markets/`](../markets/) 下对应市场卡为准。

## 1. 品类识别特征

产品图上出现以下线索时归入本类：

- 管状（唇膏、唇釉、遮瑕）、软管（洁面、护手霜）、瓶装（精华、粉底液）、罐装（面霜、发膜）
- 可见质地：膏体、液体、乳霜、粉末、凝胶
- 包装上常有成分表、净含量标注、色号标识
- 体积小，通常单手可握

涵盖：彩妆、护肤、身体护理、洗护发、口腔护理、香水。

## 2. 达人形象方向

在市场卡给出的审美框架内，本品类收窄为：

| 项目 | 方向 |
|---|---|
| 年龄段 | 22–32 岁 |
| 性别呈现 | 女性为主；男士个护或中性品类可切换为男性 |
| 气质 | 有审美但不端着，像会逛美妆店的普通女生 |
| 皮肤质感 | **必须保留真实皮肤纹理**——毛孔、细纹、绒毛。磨皮质感会立刻暴露是 AI |
| 穿着风格 | 日常家居服、针织衫、简单上衣。不要礼服感、不要明显造型感 |
| 妆容 | 已化好淡妆的状态。若产品是彩妆，要让观众能看清她本来的肤色 |
| 与产品的关系 | 首次接触并产生兴趣；**不得**设定为长期使用者或效果验证者 |

## 3. 场景与光线

按可信度排序：

1. **梳妆台 / 化妆镜前**（首选）——镜前灯或窗边自然光，桌面有些许杂物更真实
2. **浴室洗手台**——洗漱场景，镜面反光要注意控制
3. **窗边自然光下的近景**——用于质地特写，光线柔和均匀

光线要求：柔和均匀的室内自然光。避免硬光造成的高光过曝——美妆产品的质地细节一旦过曝就全废。

## 4. 钩子角度优先级

1. **痛点型**（最有效）——直接点名日常困扰。质地、显色、干燥、气色，这类问题观众一眼认领
2. **真实体验型**——表达「一直在找这样的东西」的发现感。这是本类最自然、最不油腻的角度
3. **好奇型**——利用质地、包装、开合的视觉吸引力让人停下来
4. **反差型**——使用前后的视觉差异。**注意：只能展示即时外观变化，不得暗示长期功效**

## 5. 镜头语言套路

本品类验证有效的结构：

```text
产品特写（质地在光下的反光）→ 手部拿起/开启 → 使用动作大特写 → 使用者表情或反馈 → 产品全貌收口
```

关键细节：

- **质地在光下的表现是本品类的核心画面资产**，必须有一个镜头专门给质感
- 使用动作要给**大特写**，让观众看清产品与皮肤的接触
- 最后一镜产品要立起来或正对镜头，保证观众记得住包装长相

## 6. 卖点表达重点

| 卖点类型 | 怎么表达 | 用什么镜头证明 |
|---|---|---|
| 质地 | 描述触感与延展性，不说功效 | 大特写：膏体被推开、乳液在皮肤上铺展 |
| 显色 | 描述颜色本身的观感 | 特写：颜色在皮肤上的真实呈现 |
| 肤感 | 描述涂抹时的感受 | 特写：产品与皮肤接触的瞬间 |
| 便携 | 尺寸与随身携带场景 | 中景：手持产品、放进包里 |
| 香味 | 描述气味联想的场景 | 近景：开启瞬间、使用者呼吸的细微反应 |

颜色、光泽、质地的描述要与产品图严格一致。**不得凭品类常识补全**——不要给一支哑光唇膏写「水光感」。

## 7. 常见翻车点

| 问题 | 原因 | 规避写法 |
|---|---|---|
| 手部畸形、多指 | 手部精细动作是生成模型的弱项 | 减少复杂手部动作（旋转管身、开盖拧转）；必要时改成产品已开启的状态 |
| 膏体形状在镜头间变化 | 缺乏一致性约束 | 在提示词的约束层写明产品外观锁定，见 [`../product-lock.md`](../product-lock.md) |
| 色号漂移 | 光照变化导致颜色重建 | 不要在同一段里切换色温差异大的场景 |
| 使用后皮肤状态突变 | 模型倾向于「美化」结果 | 约束层写明皮肤保持真实质感、不得平滑处理 |
| 画面过曝、质地丢失 | 硬光或高光失控 | 光线描述固定为柔和均匀，负面约束加「过曝高光」 |

## 8. 默认参数建议

- 时长：15 秒
- 镜头数量：4 个
- 画面比例：9:16
- 卖点数量：2 个以内（15 秒讲不清三个卖点）
