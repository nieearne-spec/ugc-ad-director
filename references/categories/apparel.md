# 品类路由：服饰

> 本卡只决定达人形象方向、钩子角度、镜头套路。语言、转化、支付、监管以 [`../markets/`](../markets/) 下对应市场卡为准。

## 1. 品类识别特征

产品图上出现以下线索时归入本类：

- 成衣：上衣、裤装、裙装、外套、内衣
- 鞋类：运动鞋、凉鞋、靴、拖鞋
- 包袋与配饰：背包、手提包、帽、围巾、腰带、饰品
- 可见面料质感、版型结构、走线、五金件

特征：**产品必须由人穿着或佩戴才能展示核心价值**，因此人物在画面中的占比明显高于其他品类。

## 2. 达人形象方向

| 项目 | 方向 |
|---|---|
| 年龄段 | 22–35 岁 |
| 性别呈现 | 按产品定位；中性款可交替使用 |
| 气质 | 自然的试穿感，像在给朋友看新买的东西 |
| 身形 | **必须与产品的尺码定位匹配**。写提示词时要描述身形，不要留空 |
| 穿着风格 | 展示款为主，其余为素色基础款，避免抢画面 |
| 妆发 | 日常状态。头发不要遮挡服装的关键设计点 |
| 与产品的关系 | 正在试穿与观察，**不得**宣称长期穿着体验 |

## 3. 场景与光线

按可信度排序：

1. **卧室全身镜前**——首选。镜面反射要控制，避免出现镜像错误
2. **简单纯色墙面前**——最干净的展示环境，适合突出产品本身
3. **门口玄关 / 出门前的自然光下**——适合外套、鞋类

光线要求：柔和自然光。服饰类对颜色准确度要求最高，**不要使用色温差异大的多场景**，否则同一件衣服在不同镜头里会变色。

## 4. 钩子角度优先级

1. **反差型**（最有效）——上身效果与预期的差异，或搭配前后的观感变化
2. **好奇型**——用面料、五金、结构的细节吸引停留
3. **痛点型**——点名穿着困扰（不透气、不显瘦、不好搭、磨脚）
4. **真实体验型**——平视分享发现感

## 5. 镜头语言套路

本品类验证有效的结构：

```text
产品平铺或悬挂（看清全貌）→ 上身全身（看清版型）→ 细节特写（面料/走线/五金）→ 走动或转身（看动态效果）→ 产品全貌收口
```

关键细节：

- **必须先给产品本身的完整画面**，再上人。否则观众不知道在看什么
- **全身镜头是核心**。服饰的价值在版型，版型必须靠全身展示
- **动态镜头（走动、转身）能显著提升可信度**，但也是生成难度最高的部分
- 细节镜头优先给：面料纹理、缝线、扣件、拉链、鞋底

## 6. 卖点表达重点

| 卖点类型 | 怎么表达 | 用什么镜头证明 |
|---|---|---|
| 版型 | 描述线条与轮廓 | 全身镜头：正面与侧面 |
| 面料 | 描述手感与透气感 | 大特写：面料纹理、轻微拉伸 |
| 细节 | 描述工艺的用心 | 特写：走线、五金、内衬 |
| 搭配性 | 展示与不同单品的组合 | 中景：更换一到两件其他单品 |
| 舒适度 | 描述活动中的自在感 | 近景：走动、抬手等日常动作 |

颜色描述必须**严格来自产品图**。不要凭款式印象补色——一件米色外套写成「奶油白」会在成片里变成完全不同的颜色。

## 7. 常见翻车点

| 问题 | 原因 | 规避写法 |
|---|---|---|
| **人脸在不同镜头间变化** | 人物是全片主体，一致性压力最大 | 必须用参考图方式生成（图生视频 / 参考图生视频），不要纯文生视频 |
| 服装图案漂移 | 花纹、格纹类难以锁定 | 花纹复杂的产品要降低镜头切换频率，或在约束层强化图案锁定 |
| 版型在镜头间变化 | 缺少结构与轮廓的锁定 | 在约束层写明轮廓与长度特征（如「到大腿中部」） |
| 颜色偏移 | 多场景色温差异 | 全片统一光线描述，避免冷暖和强弱跳变 |
| 鞋类结构错误 | 鞋型、鞋带、鞋底结构复杂 | 减少俯视与复杂角度，用侧面与 3/4 视角 |
| 面料质感塑料化 | 材质渲染失真 | 在提示词中明确面料的物理特性（垂坠感、厚度、光泽度），负面约束加「塑料质感」 |
| 身体比例失真 | 全身镜头难度高 | 避免极端机位（超低角度、鱼眼），保持常规人眼高度 |

## 8. 默认参数建议

- 时长：30 秒（服饰需要展示更多角度，15 秒往往不够）
- 镜头数量：30 秒 6 个；15 秒 4 个
- 画面比例：9:16
- 卖点数量：2 个以内
- **必须使用参考图生视频**，不要纯文本生视频
