# 品类路由：家居日用

> 本卡只决定达人形象方向、钩子角度、镜头套路。语言、转化、支付、监管以 [`../markets/`](../markets/) 下对应市场卡为准。

## 1. 品类识别特征

产品图上出现以下线索时归入本类：

- 收纳容器、置物架、挂件、整理盒
- 清洁工具（拖把、刷具、抹布、清洁剂容器）
- 厨房用具（切具、餐具、保鲜容器、小工具）
- 卧室与浴室用品（床品、毛巾、挂钩、皂盒）
- 装饰性用品（摆件、灯饰、织物）

特征：体积中等至偏大、以家庭空间为使用场景、功能一眼可懂、不依赖电子功能。

## 2. 达人形象方向

| 项目 | 方向 |
|---|---|
| 年龄段 | 28–40 岁 |
| 性别呈现 | 女性偏多（整理、清洁、厨房），工具类可男性 |
| 气质 | 朴实、可靠、像个真正在做家务的人 |
| 穿着风格 | 家居服、简单 T 恤、围裙。不要精致造型 |
| 手部状态 | 手要真实——指甲自然、不做过长美甲（做家务的人不会那样） |
| 与产品的关系 | 正在解决一个实际的麻烦；**不得**宣称长期使用效果 |

## 3. 场景与光线

按可信度排序：

1. **厨房操作台 / 水槽边**——本品类最可信的场景
2. **客厅沙发区 / 收纳柜前**
3. **储物间、阳台、洗衣区**——适合收纳与清洁类

光线要求：室内自然光加环境光。家居场景不怕光线不完美，轻微阴影反而增强真实感。不要打成一尘不染的样板间——**有生活痕迹的空间才有说服力**。

## 4. 钩子角度优先级

1. **痛点型**（最有效）——直接点名日常麻烦。家居品类的痛点是最容易一眼共情的：乱、难收、占地方、难清理
2. **反差型**——使用前后的场景对比。这是本类最有画面冲击力的角度
3. **好奇型**——用「这东西竟然能这样用」制造停留
4. **真实体验型**——平视分享发现感

## 5. 镜头语言套路

本品类验证有效的结构：

```text
问题场景建立（乱/挤/难用）→ 产品出场 → 使用过程 → 使用后的空间全景 → 产品全貌收口
```

关键细节：

- **开场必须先把问题拍清楚**。观众要先认可「这确实是个麻烦」，后面才有说服力
- **使用过程不要跳跃**。收纳、清洁类产品的价值在过程里，剪辑式跳切会毁掉可信度
- **结束要给一个空间全景**，让观众看到整体改善
- 最后一镜单独给产品，与开场的混乱形成对照

## 6. 卖点表达重点

| 卖点类型 | 怎么表达 | 用什么镜头证明 |
|---|---|---|
| 容量 | 用实物对比而非数字 | 中景：把多个物品依次放入 |
| 材质 | 描述手感与结实程度 | 特写：承压、拉伸、开合关节 |
| 易用 | 描述操作步骤的简短 | 特写：单手完成关键动作 |
| 省空间 | 呈现收纳前后的空间变化 | 全景：同一机位的空间对比 |
| 耐用 | 描述结构设计的可靠性 | 特写：连接处、加固部位 |

## 7. 常见翻车点

| 问题 | 原因 | 规避写法 |
|---|---|---|
| 前后场景不一致 | 模型不记忆空间布局 | 前后镜头使用同一机位描述、同一墙面与家具描述，并在约束层锁定 |
| 产品尺寸忽大忽小 | 缺少比例锚点 | 每个镜头都描述产品与参照物（手、桌面、物品）的相对关系 |
| 收纳物数量前后不符 | 模型自由发挥 | 明确写出放入物体的种类与数量 |
| 手部动作崩坏 | 开合、折叠、拧转类动作难度高 | 拆成单一动作；避免同一镜头内完成多个连续手部操作 |
| 清洁效果过于夸张 | 模型倾向于「变魔术」 | 约束层写明变化是渐进的，不要瞬间焕新 |

## 8. 默认参数建议

- 时长：15 秒（收纳清洁类可考虑 30 秒以展示完整过程）
- 镜头数量：15 秒 4 个；30 秒 6 个
- 画面比例：9:16
- 卖点数量：2 个以内
