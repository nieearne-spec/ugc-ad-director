# 镜头清单规则

镜头清单是**给用户看的拍摄说明书**，也是后面编译 Seedance 提示词的事实来源。它必须比口播脚本更细——脚本说「说什么」，清单说「画面怎么动、产品什么状态」。

## 表格格式

| 镜号 | 时间 | 景别 | 运镜 | 画面内容 | 产品状态 | 对应台词 | 备注 |
|---|---|---|---|---|---|---|---|

填写要求见下。

## 景别

只从中面五个里选，不要写「中近景」这类模糊词：

| 景别 | 画面范围 | 用途 |
|---|---|---|
| 大特写 | 产品局部或皮肤细节 | 质地、纹理、接口、走线 |
| 特写 | 产品整体填满画面 / 面部 | 产品辨识、表情反应 |
| 近景 | 胸部以上 + 手持产品 | 说话的常态镜头 |
| 中景 | 腰部以上 | 展示动作幅度、手持姿态 |
| 全景 | 能看到整个空间 | 表现空间变化、使用后全景 |

## 运镜

UGC 的运镜原则是**以稳定为主**。花哨运镜会立刻暴露制作痕迹。

| 运镜 | 写法 | 使用建议 |
|---|---|---|
| 固定 | `static` | 最常用，占多数镜头 |
| 轻微推近 | `slow push in` | 用于强调细节 |
| 轻微拉远 | `slow pull out` | 用于揭示环境 |
| 横移 | `slow pan` | 展示空间或产品全貌 |
| 手持微晃 | `handheld, slight shake` | 每个片子用一到两次，增强真实感，不要全程用 |

## 产品状态

这一列不是给自己看的，是**给一致性校验用的**。

每个镜头都要写明该镜头里产品的状态，例如：

```text
未开封 / 已开封未使用 / 正在使用中 / 使用后 / 盖回盖子
```

写清楚之后，第 9 项提示词的约束层才能据此锁死产品外观。产品状态在镜头之间跳变（比如从「未开封」直接到「使用后」）时，前后镜头必须都有交代，不能让观众觉得跳了。

## 镜头数量

| 时长 | 镜头数 | 单镜平均时长 |
|---|---|---|
| 15 秒 | 3–4 个 | 3.7–5 秒 |
| 30 秒 | 5–6 个 | 5–6 秒 |
| 45 秒 | 7–8 个 | 5.6–6.4 秒 |

**超过这个数量会导致单个镜头过短、画面跳动。**如果内容确实装不下，是卖点太多的问题，回去砍卖点，不要加镜头。

## 转场

默认使用**硬切**。AI 生成的视频里，花哨转场（旋转、缩放、遮罩）几乎必然出错或显得廉价。

需要提示转场时，只在备注列写明：`硬切` / `动作接动作`（如「掀开盖子的动作接到下一个镜头」）。

**不要使用需要画面匹配的转场**——AI 生成无法保证前后帧的连续性。

## 首镜与末镜

**首镜**：必须是钩子对应的画面，且画面本身要有信息量——一个静止的产品摆拍撑不住 0–2 秒。

**末镜**：必须包含能让观众**看清产品全貌**的画面。观众记不住产品长什么样，前面所有信息都白费。这一镜通常给特写或近景，产品正对镜头。

## 与其他项的一致性

写完清单后逐条核对：

- [ ] 每个镜头的「对应台词」都能在第 7 项脚本里找到
- [ ] 每个卖点在清单里都有对应的可视化镜头
- [ ] 产品状态的变化有合理的过渡，没有跳跃
- [ ] 末镜能看到产品全貌
- [ ] 场景描述与市场档案卡的场景建议一致
- [ ] 没有出现需要复杂手部动作的镜头，或已评估过风险（见各品类卡的「常见翻车点」）
