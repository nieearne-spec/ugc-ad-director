# 参考图策略

`@image` 锚点是视频一致性的物理基础——产品、人物、场景能不能锁住，先取决于喂进去的图合不合格。本文件定义什么图能用、怎么选、怎么排。

## 一、锚点资格：什么图能当参考

| 能用 | 不能用 |
|---|---|
| 干净的产品单体图（白底或背景不抢戏） | **带尺寸标注的图**——标注线和数字会被模型当画面元素生成出来 |
| 实拍产品照（光线正常、主体清晰） | 带无关文字、水印、价格标签的图（如包装盒整图、电商详情页截图） |
| 真实拍摄视频抽出的清晰帧 | 模糊、重影、主体被遮挡过半的图 |
| 按提示词补生成的「缺失状态」图 | 含他人肖像且无授权的图（合规红线，见 [`compliance.md`](compliance.md)） |

**图片质量优先于数量。**两张合格图好过四张互相矛盾的图。

## 二、按素材形态分流（第 0 步时判断）

| 用户给的素材 | 处理 |
|---|---|
| 干净白底三视图 | 直接当产品锚点，明确告知第 5 项可跳过 |
| 普通产品照片（多角度） | 选**主体最完整、背景最干净**的一张当主锚点，其余备用 |
| 实拍视频 | 抽帧取清晰帧当锚点（握持姿态、真实比例比白底图更有参照价值） |
| 产品有多个组成状态（如分体式、需组装） | 检查**使用态**是否有图——没有就先用文字提示词补生成一张完整组装态图（见下），再进视频生成 |
| 只有包装盒图 | 不能直接用（盒面文字会入镜）。提示用户拍产品本体，或用观察到的特征补生成 |

**缺失状态补图**：目标状态在任何素材里都找不到时，先用 `5.1/5.3` 的提示词在生图工具里补一张，验收通过后再当锚点。补图成本远低于视频反复返工。

## 三、锚点槽位与动态规则

锚点按上传顺序编号，**常用三槽**：

| 锚点 | 内容 | 是否必选 |
|---|---|---|
| `@image1` | 画面主体参考：人物（出镜时）或产品主体 | 必选 |
| `@image2` | 产品参考（有人物时）或配件/辅助参考 | 必选 |
| `@image3` | **场景参考**（见下节） | 可选 |

**动态规则（硬性）：**

1. **锚点编号 = 上传顺序。**方案包的使用说明里必须写明推荐上传顺序（如：先产品主体、再配件、最后场景），用户顺序不同必须手改编号。
2. **没传的图，编号不得出现在提示词里。**只传两张就只有 `@image1/@image2`——指向不存在图片的幽灵引用会让模型行为不可预测。
3. **约束层不得引用不存在的锚。**没传场景图时，约束层不能写 `keep the scene identical to @image3`，场景一致性退回纯文字描述（如 `keep the same light wooden desk in all shots`）。
4. 锚点数量控制在 **3 张以内**。图越多单张权重越稀释，产品一致性优先于场景一致性。

## 四、场景参考图（@image3）

**作用**：锁住镜头之间的环境一致性（桌面、墙面、光线、道具位置）；**拆段生成时必须配**——它是段与段之间场景对得上的唯一保障。

**场景图硬规范：**

- **空场景**：无产品、无手、无人物、无文字——图里有什么，模型就会把什么复制进成片
- **机位与成片一致**：用方案包设定机位拍/生成的视角（如桌面平视偏俯视），不要用与成片无关的角度
- **光线与方案包设定一致**：场景图里的光线基调必须与提示词第 1 层的描述吻合（自然光/暖光）
- **包含成片会用到的关键道具**：如键盘、瓷砖墙、镜子——这些正是要锁的对象

**何时用**：场景漂移已发生、拆段生成、复杂背景（多道具）、同一产品要做系列视频（场景图复用成资产）。

**何时可省**：单一简单背景（纯色墙、纯色瓷砖）、镜头数少且场景描述简单。

**场景图哪里来**：用户实拍（首选，手机随手拍即可）→ 按第 5.3 条提示词生成 → 实拍视频抽帧。

## 五、交付时必须写进使用说明

1. 推荐上传顺序，与锚点编号一一对应
2. 每个锚点用的是哪张图（文件名或描述）
3. 若有补生成的图：验收标准是什么（对照哪几项特征）
